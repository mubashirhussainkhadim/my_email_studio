# Leads folder rules

These rules apply to this folder only.

1. **These are made-up practice people.** Nobody in `leads.csv` is real. Use them to plan and test campaigns.
2. **Never add real people or real email addresses.** Any new row must be made up, with an address ending in `@example.com`.
3. **Every row needs a consent value.** Say how the person got in touch, for example `contact form`. Never leave it blank.
4. **Never change the `@example.com` addresses.** That domain is reserved and can never receive mail, so no real person is ever emailed.
