# Skills I chose

Notes for the Mubashir Hussain email studio (AI agents, WhatsApp automation and software for small businesses). I searched skills.sh on 8 November 2026 for "email marketing", "email sequence", "campaign plan" and "resend". Nothing is installed yet.

## Use these

**1. For writing campaigns: anthropics/knowledge-work-plugins (the marketing plugin)**
- Publisher: anthropics, the official Anthropic organization on GitHub. About 35,200 stars, updated this week.
- Its marketing plugin has the skills I need: `campaign-plan`, `email-sequence`, `brand-review` and `draft-content`.
- It did not show up in the skills.sh search results. I found it by going to the official publisher directly. Search results are sorted by installs, so a popular result is not always the best one.

**2. For sending email: resend/resend-skills**
- Publisher: resend, the company that runs the Resend email service. About 200 stars, updated this week.
- It has `resend`, `resend-cli` and `email-best-practices`. They come from the same people who build the sending API, so they should match how Resend works today.
- The star count is low, but that is fine here: the publisher is what matters. Resend's main project, resend/react-email, has about 19,900 stars, so this is a real, active team.

(Runner-up: coreyhaines31/marketingskills, about 59,100 stars, came up in almost every search. It looks good, but it is one person's account, not an official publisher. I would read it for ideas before I ran it.)

## Avoid these

**1. mbfinotti/advertising-skills (ad-budget-pacing, ad-campaign-consolidation)**
- It claims about 26,000 installs, but the GitHub repository has 2 stars and 0 forks and is only two months old. Real projects with that many users don't usually look like that, so the install count could be inflated.
- It also covers paid ads, not email, so I don't need it anyway.

**2. open.feishu.cn@lark-mail**
- It was the top result for "email marketing", with about 869,000 installs. But it is not published from a GitHub repository, so I can't see stars, history or who changes the code.
- It is built for Lark/Feishu Mail, not for marketing email or Resend. It ranks high because lots of people install it, not because it fits my studio.

## How I decided

Before installing any skill, check these three things:

1. **Who publishes it.** Prefer the official company behind the tool (anthropics, resend). Click through to the GitHub owner. Don't trust the name in the listing alone.
2. **Whether the numbers match.** Compare GitHub stars, forks and repository age with the install count. A huge install count on a tiny, new repo is a warning sign. A low star count from an official publisher is OK.
3. **What it actually does.** Open the SKILL.md and read it before installing. Check that it does what I need, and look at what it is allowed to do: which tools it runs, what scripts it ships and whether it sends data anywhere.
